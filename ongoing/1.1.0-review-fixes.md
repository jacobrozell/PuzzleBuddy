**Lane:** Bugbot · High

**Location:** `PuzzleCompletionHistorySection.swift:298-313`

**Deliverables:**

- [ ] Keep the sheet + in-form values when save throws; alert stays

## 4. Last-completion revert progress

**Lane:** Bugbot · High

**Deliverables:**

## 8. Reconcile must not treat fetch failure as empty

**Lane:** Code smells + Data integrity · High

**Locations:** `PuzzleStore.swift:603-637`, `725-740`, `320-324`

**Deliverables:**
- [ ] Fetch failure must **not** look like “no history”
- [ ] Rollback (or skip save) on delete/update failure
- [ ] Unit test: simulated fetch failure does not zero `timesCompleted`
