## 1. Unversioned 1.0.0 → V2 disk migrate; no wipe

**Lane:** Data integrity + Architecture · **Block 1.1.0**

Live 1.0.0 opened an **unversioned** `Schema([PuzzleRecord, PuzzlePhotoRecord, PuzzleCompletionRecord])` with no plan. 1.1.0 opens `PuzzleSchemaV2` + `PuzzleMigrationPlan`. Nested `PuzzleSchemaV1` models never wrote a production store. Open failure in `makePersistent()` **deletes** the sqlite files (`model_container_store_reset`).

**Locations:** `PuzzleModelContainer.swift:36-103` · `PuzzleSchemaV1.swift:18-27` · `PuzzleMigrationPlan.swift:19-26`

**Deliverables:**
- [ ] Confirm how SwiftData treats an unversioned 1.0.0 store when opened as versioned V2
- [ ] Migration path that preserves puzzles, photos, and completions (lightweight or custom). Do **not** ship wipe-on-unknown-version for this upgrade
- [ ] Disk test: write a store with the **1.0.0 opener** (unversioned top-level models — not nested V1, not `makeInMemory()`), seed puzzle + cover + ≥2 completions, reopen with production V2 + plan
- [ ] Assert same IDs, photos, completion rows/dates/numbers; `isOnLoan == false`; loan fields nil; `markStoreWasReset()` is **not** called

Until this passes, assume every 1.0.0 upgrader can lose the collection.

## 3. Edit sheet stays open on save failure

**Lane:** Bugbot · High

`onSave(updated)` always `dismiss()`es. `saveCompletion` catches persistence errors and only shows an alert, so a failed save closes the editor and looks like it applied.

**Location:** `PuzzleCompletionHistorySection.swift:298-313`

**Deliverables:**

- [ ] Keep the sheet + in-form values when save throws; alert stays

**Deliverables:**

## Suggested 1.1.0 App Review notes

From the App Store policy lane. Paste into Connect after #21.

> Puzzle Buddy 1.1.0 is a local-first jigsaw catalog. No account or login. Requires iOS 18.
>
> **Demo data:** Settings → Collection → Load Demo Data (adds 13 sample puzzles; existing user puzzles are kept). Remove Demo Data removes only those samples.
>
> **New in 1.1 (how to review):**
> - Completion history: open **Floral Arch** (completed twice) → edit or delete a finish.
> - Undo complete: mark a puzzle Complete, then use the undo banner (same session).

>
> **Not shipped (do not look for these):** People / Friends list UI is off. Settings import/export was removed. There is no barcode product-lookup toggle or network catalog. Barcodes are on-device only (duplicate check + suggestions from saved puzzles). Camera required for scan; simulators show “Scanner unavailable” and manual barcode entry still works.
>
> **Privacy:** Collection, photos, notes, and optional borrower names stay on device. Firebase Analytics and Crashlytics only (allowlisted events; no titles, photos, or names). Privacy: https://jacobrozell.github.io/PuzzleBuddy/privacy.html
>
> Brand names in the catalog are for identification only. Settings → Help & Legal has the manufacturer disclaimer.
