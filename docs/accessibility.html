Accessibility

Puzzle Buddy for iPhone, iPad, and Android

Puzzle Buddy is committed to making the app usable for everyone. We follow WCAG 2.1 Level AA as a target for the iPhone, iPad, and Android apps, and work toward full conformance over time.

Conformance status

Partial conformance with WCAG 2.1 Level AA. Core flows (puzzle list, add puzzle, settings) have screen-reader labels and follow the system text size and appearance. Some screens, including the star rating, are still being improved.

Supported features

  • Screen reader — VoiceOver on iPhone and iPad, TalkBack on Android. Labels cover the puzzle list, add puzzle, settings, and tab navigation.
  • Text size — iPhone and iPad follow Dynamic Type. Android follows the system font size.
  • Dark mode — Light and dark colors on every platform.
  • Reduce Motion — On iPhone and iPad, the decorative background stays still when Reduce Motion is on. Android does not yet follow the system remove-animations setting for the splash.

Known limitations

  • Layout at the largest accessibility text sizes is not yet fully verified on all screens
  • The app is currently available in English only

WCAG 2.1 principles we apply

Principle What it means in Puzzle Buddy
Perceivable Text alternatives and labels for controls; sufficient color contrast on primary actions; support for larger text
Operable Touch, VoiceOver, and TalkBack navigation; no time limits. iPhone and iPad honor Reduce Motion for the decorative background.
Understandable Clear field labels, consistent tab navigation, error messages in plain language
Robust System controls and accessibility APIs on iPhone, iPad, and Android so assistive technology can interpret the interface

Testing with assistive technology

On iPhone or iPad, open Settings → Accessibility:

  • VoiceOver — Spoken descriptions of on-screen elements
  • Larger Text — Increase text size under Display & Text Size
  • Reduce Motion — Limits non-essential animation
  • Voice Control — Navigate and activate controls by voice

On Android, open Settings → Accessibility:

  • TalkBack — Spoken descriptions of on-screen elements
  • Font size and Display size — Increase text and controls
  • Voice Access — Navigate and activate controls by voice, where the device offers it

Feedback

If you encounter a barrier when using Puzzle Buddy, please contact us via Support. Helpful details include:

  • Whether you are on iPhone, iPad, or Android, and the OS version
  • Which assistive feature you use (for example VoiceOver, TalkBack, or larger text)
  • What you were trying to do and what happened instead

We review accessibility feedback regularly and prioritize fixes that block core tasks (adding puzzles, viewing your collection, settings).
